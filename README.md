# emanueleguerrini.com

Sito personale di Emanuele Guerrini — energy engineering & industrial advisory.

Sorgenti della versione V2, pagine in italiano e inglese, CSS, JavaScript e modulo contatti PHP.

**Pubblicazione:** collegare questo repository (branch `main`) al sito `emanueleguerrini.com` su Hostinger hPanel > Siti web > Gestisci > Avanzate > Git. Verificare prima la cartella di destinazione e fare un backup di eventuali contenuti esistenti.

**Nota:** il modulo contatti resta non operativo finché il destinatario in `contact-config.php` non viene configurato sul server e testato. Completare gli adempimenti privacy prima di raccogliere dati.

Non inserire password, chiavi o token nel repository.
